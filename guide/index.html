GETTING STARTED

내 근무에 맞게,
네 단계로 시작하세요.

처음 사용하는 분을 위한 안내입니다. 근무표 직접 입력부터 차근차근 시작해 보세요.

STEP 1

근무표를 직접 등록하세요.

하단 ‘근무표’에서 월간 달력을 확인하세요. ‘수정’을 눌러 날짜별 근무를 입력합니다. 병원 고유 코드는 근무형태 설정에서 추가할 수 있습니다.

근무표 → 수정 → 날짜별 근무 입력

STEP 2

근무별 반복 업무를 설정하세요.

설정의 ‘근무별 기본 루틴 만들기/편집’에서 기본 루틴을 조정할 수 있습니다. ‘나만의 루틴 만들기/편집’에서는 근무형태에 맞는 개인 반복 업무를 구성하세요.

기본 루틴과 개인 루틴은 각 편집 화면에서 설정

STEP 3

‘오늘’에서 Today 업무를 확인하세요.

하단 ‘오늘’에서 선택한 날짜와 근무에 해당하는 업무를 살펴보세요. 출근 전, 근무 중, 퇴근 전·후 흐름에 맞춰 확인할 수 있습니다.

오늘 → 근무에 해당하는 업무 확인

STEP 4

완료한 일은 체크하고, 필요한 일은 추가하세요.

업무의 체크박스로 완료 여부를 표시합니다. 필요한 업무는 ‘+’로 추가하고, 연필 아이콘으로 업무 내용을 수정할 수 있습니다.

완료 체크 · + 업무 추가 · 연필 아이콘으로 수정

사진 가져오기는 선택 기능이에요.

‘근무표 사진으로 불러오기 BETA’에서 사진과 본인 행을 직접 선택합니다. 인식 결과의 날짜·근무코드를 검토하고 연월을 확인한 뒤 적용하세요. 사진 분석 없이 직접 입력해도 됩니다.
